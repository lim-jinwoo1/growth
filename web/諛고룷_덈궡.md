# 동반성장 페이지 인터넷 주소 만들기 (GitHub Pages)

## 준비물
- `index.html` (페이지 본체 · 이 안에 데이터·디자인·기능이 전부 들어 있음)
- `robots.txt` (검색엔진 차단)
- `.nojekyll` (빈 파일 · GitHub이 파일을 임의로 손대지 않게 함)
- `pdf/` 폴더 (발송본 PDF · 있을 때만. 뉴스레터 탭의 [PDF 내려받기] 단추가 이걸 가리킴)

모두 함께 드렸습니다. **서버·데이터베이스·설치 필요 없습니다.**

---

## 최초 1회만 하는 작업 (약 5분)

### 1단계 · GitHub 계정
https://github.com 에서 계정을 만드시거나, 이미 있으면 로그인합니다.
※ 이 단계는 대신 해드릴 수 없습니다(계정 생성·로그인). 나머지는 클릭 몇 번입니다.

### 2단계 · 저장소(Repository) 만들기
1. 오른쪽 위 **+** → **New repository**
2. **Repository name** : `growth` (원하는 이름으로. 주소에 그대로 들어갑니다)
3. **Public** 선택
   → Private은 무료 계정에서 Pages가 안 켜집니다. 검색 차단은 `robots.txt`로 걸어뒀으니
     링크를 아는 사람만 열게 됩니다.
4. **Create repository**

### 3단계 · 파일 올리기
1. 저장소 화면의 **uploading an existing file** 링크 클릭
   (이미 파일이 있으면 **Add file → Upload files**)
2. `index.html`, `robots.txt`, `.nojekyll` 을 끌어다 놓기
   `pdf` 폴더가 있으면 **폴더째로** 함께 끌어다 놓습니다 (폴더 구조가 유지됩니다)
3. 아래 **Commit changes** 클릭

### 4단계 · Pages 켜기
1. 상단 **Settings** → 왼쪽 메뉴 **Pages**
2. **Source** : `Deploy from a branch`
3. **Branch** : `main` / 폴더는 `/ (root)` → **Save**
4. 1~2분 뒤 같은 화면 위쪽에 주소가 뜹니다

### 완성된 주소 모양
```
https://<계정이름>.github.io/growth/
```
예 : 계정이 `krb-esg` 라면 → `https://krb-esg.github.io/growth/`

---

## 이후 수정하는 방법 (주소 그대로 유지)

수정 요청을 주시면 제가 **새 `index.html`을 만들어 드립니다.** 그 다음:

1. 저장소에서 `index.html` 클릭
2. 연필 아이콘(Edit) 옆 **⋯ → Delete file** 후 새 파일 업로드
   또는 **Add file → Upload files** 로 같은 이름 파일을 올리면 자동으로 덮어씁니다
3. **Commit changes** → 1분 뒤 반영

**주소는 절대 바뀌지 않습니다.** 저장소 이름을 바꾸거나 지우지만 않으면 됩니다.

> 더 편한 방법 : GitHub를 Claude에 연결해 두시면, 다음부터는 제가 직접 파일을 갱신해
> 커밋까지 처리할 수 있습니다. 그러면 "시세 업데이트해줘" 한 마디로 끝납니다.

## 주소를 더 짧게 (선택)

사내 도메인이 있으면 붙일 수 있습니다. 예 : `esg.krb.co.kr`

1. IT팀에 DNS **CNAME** 레코드 추가 요청
   → `esg` → `<계정이름>.github.io`
2. GitHub 저장소 **Settings → Pages → Custom domain** 에 `esg.krb.co.kr` 입력
3. **Enforce HTTPS** 체크 (무료 인증서가 자동 발급됩니다)

## 공개 범위 점검 결과

이 페이지에 들어간 것과 안 들어간 것입니다. 지난번 정하신 기준을 그대로 따랐습니다.

**들어간 것 (공개 가능)**
- 장학금 전달 지역·날짜·인원·금액 — 모두 이미 언론에 보도된 내용
- 원자재·환율 시세 : 당일값 · 당월 평균 · 전월 대비 증감률
- 협력사에 발송한 주간 뉴스레터 원본

**들어가지 않은 것 (비공개)**
- 사업계획 기준시세, vs 계획 대비율
- 원가영향 금액(백만원), 매입비중 가중, 원화환산 실질변동
- 배합비, 업체명·주소·거래조건·단가
- 협력사 레이어 (현재 스위치 OFF)

**추가 안전장치**
- `robots.txt` + `noindex` 태그 → 검색엔진 색인 차단
- `referrer: no-referrer` → 외부 링크 클릭 시 이 주소가 상대 서버에 남지 않음

## 발송본 PDF 내려받기 단추 (2026-09-10 추가)

뉴스레터 탭에서 호를 고르면 오른쪽 위에 **[↓ PDF 내려받기]** 단추가 나옵니다.
누르면 그 호의 발송본 PDF가 바로 저장됩니다.

### 어떻게 켜지나
그 호에 PDF 파일이 **실제로 있을 때만** 단추가 나옵니다. 없는 호에는 아예 안 나옵니다
(빈 링크를 눌러 404를 보는 일이 없게 했습니다).

켜는 절차는 두 단계입니다.

1. **파일을 작업폴더의 `pdf/` 에 넣습니다.**
   `letter1p.py` 가 만든 PDF를 복사하고, 이름은 **영문·숫자로** 바꿉니다.
   ```
   pdf/Kiturami_Newsletter_2026-36.pdf
   ```
   > 한글 파일명을 쓰면 일부 브라우저가 이름을 버리고 `download` 라는 이름으로
   > 저장합니다(크로미움에서 실제로 재현됨). 그래서 영문 이름을 씁니다.

2. **`issues.json` 의 그 호에 `pdf` 줄을 한 줄 넣습니다.**
   ```json
   { "vol": "2026-36", "start": "2026-08-31", "end": "2026-09-06",
     "pdf": "pdf/Kiturami_Newsletter_2026-36.pdf",
     "items": [ ... ] }
   ```

그 다음 `python mk.py` → `python mk_web.py` 를 돌리면 `web/pdf/` 로 자동 복사되고
단추가 살아납니다. **`index.html` 안에는 PDF가 들어가지 않고 경로만 링크**되므로
호가 늘어도 페이지 용량은 그대로입니다.

### 용량 계산
발송본 1장 = 약 150KB. 1년 52호를 다 올려도 약 7.8MB 로, GitHub 무료 저장소 한도
(권장 1GB)의 1% 미만입니다.

### 주의
PDF는 **누구나 주소를 알면 내려받을 수 있습니다.** `robots.txt` 로 검색은 막지만
파일 자체에 잠금은 없습니다. 발송본에는 공개 가능 항목만 들어가므로 문제는 없지만,
비공개 수치가 들어간 문서는 이 폴더에 두지 마십시오.
